PC PLUS COMPUTING - RMM SCRIPTS REFERENCE
==========================================
Last Updated: July 5, 2026

All scripts are deployed via Tactical RMM (api.pcpluscomputing.com)
Shell: PowerShell | Run As: System (unless noted)

======================================================================
SCRIPT 185: Network Sentry Install
----------------------------------------------------------------------
Purpose: Install Network Sentry monitoring agent on Windows endpoint
What it does:
  - Installs Sysmon for detailed event logging
  - Configures Windows Event forwarding
  - Sets up scheduled task for periodic sentry checks
  - Reports back to CMD dashboard
When to use: New endpoint onboarding

SCRIPT 206: PCPlus Deep Security Scan
----------------------------------------------------------------------
Purpose: Comprehensive security audit of an endpoint (252 lines)
What it does:
  - Scans all user accounts and permissions
  - Checks failed/successful login attempts with IPs/countries
  - USB device history
  - File access audit trail

  - Pushes full JSON report to CMD via HTTPS

======================================================================
SCRIPT 207: PCPlus Block RDP Port
----------------------------------------------------------------------
Purpose: Block inbound port 3389 (RDP) in Windows Firewall
What it does:
  - Creates firewall rule "PCPlus - Block RDP Port 3389" blocking inbound TCP 3389
  - Disables RDP service
  - Disables built-in Remote Desktop firewall rules
When to use: Blocking external RDP access on endpoints
Note: Use Script 208 to reverse this

======================================================================
SCRIPT 208: PCPlus Unblock RDP Port
----------------------------------------------------------------------
Purpose: Remove RDP block and re-enable Remote Desktop
What it does:
  - Removes "PCPlus - Block RDP Port 3389" firewall rule
  - Enables RDP in registry (fDenyTSConnections = 0)
  - Enables Windows Remote Desktop firewall rules
  - Starts and sets TermService to Automatic
  - Verifies port 3389 is listening
When to use: When an office needs RDP access (internal/VPN use)
Note: Reverses Script 207

======================================================================
SCRIPT 209: PCPlus Check Wazuh Agent
----------------------------------------------------------------------
Purpose: Diagnostic check of Wazuh agent installation
What it does:
  - Checks WazuhSvc/OssecSvc service status
  - Finds install path (x86 and x64)
  - Reports configured manager address
  - Reads agent state file (connected/pending/disconnected)
  - Tests network connectivity to manager (10.50.1.10:1514)
When to use: Troubleshooting Wazuh agent connectivity issues

======================================================================
SCRIPT 210: PCPlus Deploy Wazuh Agent
----------------------------------------------------------------------
Purpose: Install or fix Wazuh agent on any Windows endpoint
What it does:
  - If agent exists with correct config: verifies connection, restarts if needed
  - If agent exists with wrong manager: updates config to 65.7.31.82, restarts
  - If no agent: downloads Wazuh 4.14.6 MSI, installs silently with
    WAZUH_MANAGER=65.7.31.82, starts service
  - Verifies service is running after install
When to use: New endpoint onboarding, fixing disconnected Wazuh agents
Manager: 65.7.31.82 (Server 18)
